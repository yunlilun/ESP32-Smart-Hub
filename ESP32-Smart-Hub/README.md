# ESP32 Smart Hub (物联网多模态控制终端)

基于 ESP32 开发的一款多功能集成仪表盘与 Web 控制终端。

##  功能特性
- **旋转编码器菜单**：带有多级菜单滚动、单击进入、双击退出逻辑。
- **倒车雷达**：超声波测距，带非阻塞蜂鸣器声光报警（距离越近声音越急促）。
- **温湿度监测**：实时读取 DHT11 数据并显示。
- **心率监测**：利用 ADC 采样与波峰检测算法计算心率 (BPM)。
- **声音分贝仪**：基于 ADC 采样计算 Vpp（峰峰值），并通过对数公式转换为相对分贝 (dB)。
- **红外接收**：实时捕捉红外遥控信号。
- **继电器控制**：直接在屏幕或网页端控制外部设备。
- **WiFi 热点与 Web 服务器**：一键开启 AP 热点，手机连接后可访问网页，实时查看所有传感器数据，并支持通过网页反向控制继电器。

##  硬件接线表
| 模块 | 引脚 | 接 ESP32 | 备注 |
| :--- | :--- | :--- | :--- |
| **OLED 屏幕** | SCL / SDA | GPIO 22 / 21 | 3.3V 供电 |
| **旋转编码器** | CLK / DT / SW | 32 / 33 / 25 | 3.3V 供电 |
| **超声波** | Trig / Echo | 5 / 18 | 5V 供电 |
| **有源蜂鸣器** | I/O | 4 | 3.3V 供电 |
| **DHT11 温湿度** | DATA | 15 | 3.3V 供电 |
| **继电器** | IN | 16 | 5V 供电 |
| **心跳传感器** | S | 34 | 3.3V 供电 |
| **红外接收** | OUT | 14 | 3.3V 供电 |
| **声音传感器** | AO | 35 | 3.3V 供电 |

##  Web 控制端使用说明
1. 在屏幕上开启 `WiFi [ON]`。
2. 使用手机连接 WiFi 热点：`ESP32_Smart_Home`，密码：`12345678`。
3. 打开手机浏览器，访问 `192.168.4.1` 即可进入控制面板。

##  编译环境
- **开发板**：ESP32 Dev Module (ESP32-WROOM-32)
- **环境**：Arduino IDE / Mind+ (基于 Arduino 框架)
- **依赖库**：`U8g2`, `DHT sensor library`, `Adafruit Unified Sensor` (WiFi/WebServer 为 ESP32 核心内置库)
